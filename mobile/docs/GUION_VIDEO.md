# Guion sugerido de defensa - máximo 15 minutos

Duración propuesta: 12 a 14 minutos. El equipo debe grabar su explicación y validar el enlace en una sesión sin autenticación.

| Tiempo | Mostrar y explicar |
| --- | --- |
| 0:00-1:00 | Presentar Comerciales Mely, el problema que resuelve y los mockups de Figma de la Etapa 1. |
| 1:00-2:30 | Explicar la arquitectura React/Next.js y React Native/Expo: UI, lógica de negocio, Context y datos. |
| 2:30-4:00 | Mostrar inicio y registro por correo, recuperación de contraseña y Google en web; explicar Firebase Auth móvil y requisito de APK nativa. |
| 4:00-6:00 | Abrir el mismo catálogo en web y móvil; buscar, crear/editar y archivar un producto según el rol. |
| 6:00-7:30 | Registrar una entrada/salida y mostrar cómo el cambio de stock y su movimiento se guardan juntos. |
| 7:30-10:00 | Crear una venta como Facturador; explicar validación de existencias, subtotal, IVA del 13 %, factura y salida de bodega. |
| 10:00-11:00 | Mostrar alertas, reportes y roles; distinguir ventas de utilidad. |
| 11:00-12:00 | Refrescar la otra plataforma y mostrar la persistencia compartida en Firestore. |
| 12:00-13:00 | Mostrar reglas de Firestore, pruebas de lógica, guía de instalación y matriz de criterios. |
| 13:00-14:00 | Comparar las pantallas con los mockups y explicar límites comprobados de despliegue, Android/iOS y trabajo colaborativo. |

Preguntas para practicar: ¿Por qué el stock no se modifica desde editar producto? ¿Qué ocurre si falla una línea de la venta? ¿Por qué se usan centavos? ¿Cómo evitan las reglas que un usuario se asigne administrador? ¿Cómo comparten web y móvil el mismo dato? ¿Qué configuración requiere Google Sign-In nativo?

Cada integrante debe explicar código que comprenda. No atribuir commits o trabajo a personas que no lo hayan realizado.
