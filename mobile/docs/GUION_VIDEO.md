# Guion sugerido de defensa - máximo 15 minutos

Duración propuesta: 12 a 14 minutos. El equipo debe grabar su explicación y validar el enlace en una sesión sin autenticación.

| Tiempo | Mostrar y explicar |
| --- | --- |
| 0:00-1:00 | Presentar Comerciales Mely, problema del negocio y alcance del Foro 1. |
| 1:00-2:30 | Explicar React Native, View/Text/TextInput, StyleSheet y arquitectura UI/lógica/datos. |
| 2:30-4:00 | Login incorrecto, registro con validación, acceso correcto y permisos del empleado. |
| 4:00-6:00 | Buscar producto, crear/editar, cargar imagen y explicar FlatList y Context API. |
| 6:00-7:30 | Registrar entrada y rechazar salida superior al stock. Mostrar historial. |
| 7:30-10:00 | Facturador: carrito, cantidades, subtotal, IVA y confirmación. Mostrar descuento y comprobante PDF. |
| 10:00-11:00 | Reportes: barras y fecha local; distinguir valor de inventario de utilidad. |
| 11:00-12:00 | Cerrar/reabrir app; demostrar persistencia SQLite y cierre de sesión. |
| 12:00-13:00 | Mostrar pruebas y función transition: validar antes de persistir. |
| 13:00-14:00 | Contrastar con Figma original con las capturas originales de docs/diseno y reconocer pendientes de Firebase/iOS. |

Preguntas para practicar: ¿Por qué el stock no se modifica desde editar producto? ¿Qué ocurre si falla la segunda línea de la venta? ¿Por qué se usan centavos? ¿Qué valida el rol fuera de la pantalla? ¿Dónde queda la imagen? ¿Qué falta para compartir datos con la web?

Cada integrante debe explicar código que comprenda. No atribuir commits o trabajo a personas que no lo hayan realizado.
